# Chapter 28: Reinforcement Learning — CartPole with PPO

Reinforcement learning (RL) trains an agent to make decisions by interacting with an environment. This chapter walks through tinygrad's CartPole example, which uses Proximal Policy Optimization (PPO).

## The Setup

In CartPole, a pole is balanced on a cart. The agent can push the cart left or right. The goal: keep the pole upright for as long as possible.

```
        │
        │  <- pole (must stay upright)
   ┌────┴────┐
   │  cart   │
───┴─────────┴───  <- track
     ← push →
```

- **State**: cart position, cart velocity, pole angle, pole angular velocity (4 numbers)
- **Actions**: push left (0) or push right (1)
- **Reward**: +1 for each timestep the pole stays upright
- **Done**: pole falls past 12° or cart leaves the track

## Actor-Critic Architecture

The model has two heads sharing a common input:

```python
class ActorCritic:
    def __init__(self, in_features, out_features, hidden_state=32):
        # Actor: picks actions
        self.l1 = nn.Linear(in_features, hidden_state)
        self.l2 = nn.Linear(hidden_state, out_features)
        # Critic: estimates value
        self.c1 = nn.Linear(in_features, hidden_state)
        self.c2 = nn.Linear(hidden_state, 1)

    def __call__(self, obs: Tensor):
        act = self.l2(self.l1(obs).tanh()).log_softmax()  # log probabilities
        val = self.c2(self.c1(obs).relu())                # state value
        return act, val
```

**Actor** outputs a probability distribution over actions (left/right). **Critic** estimates how good the current state is (expected future reward).

## PPO: Proximal Policy Optimization

PPO is the most popular RL algorithm. It updates the policy (actor) while preventing too-large changes that could destabilize training.

### The Key Idea

```python
# ratio = new_policy / old_policy
ratios = (log_dist - old_log_dist).exp()

# Clip the ratio to [1-epsilon, 1+epsilon]
unclipped = masked_advantage * ratios
clipped = masked_advantage * ratios.clip(1 - PPO_EPSILON, 1 + PPO_EPSILON)

# Take the minimum (pessimistic update)
action_loss = -unclipped.minimum(clipped).sum(-1).mean()
```

If the new policy is too different from the old one (ratio far from 1.0), the clipping prevents the update from being too aggressive. This is what makes PPO stable.

### The Three Losses

```python
# 1. Policy loss: encourage actions that led to high advantage
action_loss = -unclipped.minimum(clipped).sum(-1).mean()

# 2. Entropy loss: encourage exploration (don't be too certain)
entropy_loss = (log_dist.exp() * log_dist).sum(-1).mean()

# 3. Value loss: critic should predict accurate returns
critic_loss = advantage.square().mean()

# Combined
total_loss = action_loss + entropy_loss * 0.0005 + critic_loss
```

### Advantage

The **advantage** measures how much better an action was compared to the average:

```python
advantage = reward_to_go - value_estimate
```

If `advantage > 0`, the action was better than expected → increase its probability.
If `advantage < 0`, the action was worse than expected → decrease its probability.

### Reward-to-Go

Future rewards are discounted — a reward now is worth more than a reward later:

```python
DISCOUNT_FACTOR = 0.99
# For a sequence of rewards [1, 1, 1, 1, 1]:
# reward_to_go[0] = 1 + 0.99 + 0.99^2 + 0.99^3 + 0.99^4 = 4.90
# reward_to_go[4] = 1
discounts = np.power(DISCOUNT_FACTOR, np.arange(len(rews)))
Rn = [np.sum(rews[i:] * discounts[:len(rews)-i]) for i in range(len(rews))]
```

Key differences from supervised learning:
- **No fixed dataset** — the agent generates its own training data by interacting with the environment
- **Delayed reward** — the agent doesn't know if an action was good until the episode ends
- **Non-stationary** — as the policy improves, the data distribution changes

## RL vs Supervised Learning

| | Supervised Learning | Reinforcement Learning |
|--|-------------------|----------------------|
| Data | Fixed dataset (X, Y) | Agent generates data by acting |
| Feedback | Immediate (loss per sample) | Delayed (reward at end of episode) |
| Objective | Minimize prediction error | Maximize cumulative reward |
| Exploration | Not needed | Critical (try new actions) |
| Examples | MNIST, GPT-2 | CartPole, game playing, robotics |
